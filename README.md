**RU:** Полноценная операционная система, написанная с нуля. Без Buildroot. Без Yocto. Без LFS. Загрузчик, ядро, драйверы, библиотеки, оконный сервер — всё своё. Верифицированное микроядро seL4, драйверы и сервисы — в userspace.

- 🚀 **Zero-copy IPC** — shared memory, minimal copying / разделяемая память, минимум копирования

- 📦 **kzl-fs** — own filesystem, no extra layers / своя ФС без лишних слоёв

<summary>⚙️ <b>КАК ВКЛЮЧИТЬ ЗМЕЙКУ / HOW TO ENABLE THE SNAKE</b> (клик, там 2 минуты)</summary>

1. Змейка живёт в твоём **профильном репозитории** `kizill-top-jr/kizill-top-jr` (там же, где этот README).
2. Создай файл `.github/workflows/snake.yml` со следующим содержимым:

```yaml
name: Generate Snake
on:
  schedule:
    - cron: "17 3 * * *"
  workflow_dispatch:
  push:
    branches: [master, main]
jobs:
  generate:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: Platane/snk/svg-only@v3
        with:
          github_user_name: kizill-top-jr
          outputs: |
            dist/github-contribution-grid-snake.svg?color_snake=#00FF00&color_dots=#161b22,#00FF00
            dist/github-contribution-grid-snake-dark.svg?color_snake=#FF0000&color_dots=#161b22,#FF0000

        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

3. Запусти экшен вручную: **Actions → Generate Snake → Run workflow** (или просто запушь коммит).
