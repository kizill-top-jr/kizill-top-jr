## 🧠 **Философия Kizill_OS (для тех, кто в теме)**

- **Микроядро на базе seL4** — верифицированная стабильность, драйверы в userspace.
- **Адаптивные профили ядра** — турбо/стабильный режимы с автопереключением по метрикам.
- **Быстрый IPC** — разделяемая память, без копирования.
- **Собственный оконный сервер** — ягодная тема: чёрный фон, красные/зелёные акценты.
- **Цель загрузки** — < 5 сек CLI, < 10 сек GUI.
- **Файловая система** — своя, лёгкая, без тонны зависимостей.
