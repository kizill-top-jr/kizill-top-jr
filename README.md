## ⚡ **Мои творения — не игрушки**

| Проект | Суть | Стек |
|--------|------|------|
| **QssGramDesktop** | Telegram-клиент с кастомизацией через QSS. Основа: AyuGram + моя магия. | C++, Qt, QSS |
| **Kizill_OS** | Полноценная ОС с нуля. Микроядро seL4, драйверы в userspace. | C, Assembly, UEFI |

---

## 🧠 **Философия Kizill_OS**

> ⚡ Адаптивные профили ядра (турбо/стабильный)  
> ⚡ Быстрый IPC на разделяемой памяти  
> ⚡ Свой оконный сервер (ягодная тема)  
> ⚡ Загрузка < 5 сек CLI, < 10 сек GUI  
> ⚡ Своя ФС без тонны зависимостей
